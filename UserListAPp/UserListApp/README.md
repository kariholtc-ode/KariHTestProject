## Features
- App name: **UserListApp**
- Fetch Users button sends a GET request to `https://jsonplaceholder.typicode.com/users`
- Parses and displays each user's name, email, and phone from the JSON response
- Custom `UserAdapter` and `UserViewHolder`
- Toast message `You selected.` when a row is tapped
- Toast message `Failed to fetch data.` if the request fails
- Progress indicator while loading
